### 🚀 Cara Pakai

1. **Download** file `RKDKCW_Audio_Studio.zip` atau `RKDKCW_Launcher.exe` dari link di atas.
2. **Ekstrak** filenya ke folder mana saja di komputer kamu.
3. **Buka / Klik 2x `RKDKCW_Launcher.exe`**:
   - Launcher otomatis memeriksa pembaruan.
   - Server otomatis menyala dan langsung membuka dashboard studio di browser kamu (`http://127.0.0.1:5000/app`).
